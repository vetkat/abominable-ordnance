# Slice 3 (larva launcher) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use
> superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps
> use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fire loaded larvae from a larva launcher. A larva rocket lands
with a small blast, and its loaded monster appears at full health.
Research upgrades the fire rate and the range.

**Architecture:** Pure core modules build the prototypes
(`core/prototypes/ordnance.lua`, `core/prototypes/launcher.lua`) and make
the runtime decisions (`core/trail.lua`, `core/launcher.lua`,
`core/flare.lua`, `core/payloads.lua`). `data.lua`,
`data-final-fixes.lua`, `control.lua` and `shell/launcher.lua` stay thin
shells. The launcher is an artillery turret, and the loaded larvae are
its ammo.

**Tech Stack:** Factorio 2.1.24 Lua, busted for the core, factorio-test
for the in-game tests, `make check` for all gates.

**Spec:** `docs/superpowers/specs/2026-11-14-launcher-design.md`
(approved 2026-11-14, with separate remotes as written).

## Global Constraints

- The target is Factorio 2.1, with and without Space Age.
- Every number lives in `core/balance.lua`.
- A core module never names `game`, `storage`, `script`, `defines`,
  `prototypes`, `rendering`, `helpers`, `remote`, `commands`, `rcon`,
  `settings`, `mods` or `data`. `spec/architecture_spec.lua` enforces
  this.
- No file in `core/`, `shell/` or `control.lua` uses `math.random`.
- Every new item, recipe, technology and entity gets a name in
  `locale/en/locale.cfg`. `spec/locale_spec.lua` enforces this.
- A change to mod code gets a line under Unreleased in `CHANGELOG.md`.
- Commits: `make format`, `git add`, `make stamp`, `git commit`, each as
  its own command. Each PR body has the `## Review angles` section, and
  each PR uses `gh pr merge --auto --squash`.
- Look up each Factorio API name in `.factorio-api/factorio/library/`.
- Range: 64, 80, 96 and 112 tiles automatic. The remote reaches 1.5
  times that.
- The landing blast: 35 explosion damage in a 3.5-tile radius, only to
  forces at war with the launcher's force.

  monster to hatch next to the launcher on the tamed force, not to lose
  the rocket silently. Task 8 pins it.
- **Mining a launcher at level 2.** The player expects the
  `ao-larva-launcher` item back, not a hidden level item. Task 10 pins

  not swap the other force's launchers. Task 10 pins it.

## Ledger rulings made while planning

- **A third trail field, `storage.trail_next_tick`.** The spec names two
  fields. Without a start time per pass, a few acid monsters would leave
  a puddle every tick instead of once a second. Cost if wrong: one field.
- **The 300-monster cadence is a busted test.** Spawning 300 monsters in
  the in-game tests is slow. The pure `Trail` functions prove the
  cadence, and an in-game test covers the shell with a few monsters.
  Cost if wrong: a shell bug that only shows at high counts.

Create `core/trail.lua`:

```lua
-- Splits the acid trail into small batches, so that its cost per tick
-- stays fixed however many monsters walk. Pure: it reads only its
-- parameters.
local Trail = {}

-- Up to n keys of t after cursor, and the cursor for the next call. The
-- cursor is nil when the pass reached the end of t. A cursor whose key
-- left t counts as the start of t.
function Trail.batch(t, cursor, n)
  if cursor ~= nil and t[cursor] == nil then
    cursor = nil
  end
  local got = {}
  local key = cursor
  for _ = 1, n do
    key = next(t, key)
    if key == nil then
      break
    end
    got[#got + 1] = key
  end
  return got, key
end

-- The cursor to keep when key leaves t. Call it while t[key] still
-- exists: next() needs the key in the table.
function Trail.forget(t, cursor, key)
  if cursor ~= nil and cursor == key then
    return next(t, key)
  end
  return cursor
end

-- Whether the handler works this tick, and the tick when the next pass
-- may start. A new pass starts at most once per interval, so a few
-- monsters still leave one puddle a second.
function Trail.start(cursor, tick, next_tick, interval)
  if cursor ~= nil then
    return true, next_tick
  end
  if tick < (next_tick or 0) then
    return false, next_tick
  end
  return true, tick + interval
end

return Trail
```

```lua
-- The levels of the larva launcher: names, guns and ranges. Pure data
-- and lookups.
local Balance = require("core.balance")
local Names = require("core.names")

local Launcher = {}

local MAX = Balance.launcher.max_level

local function known(level)
  return type(level) == "number" and level >= 1 and level <= MAX and level % 1 == 0
end

-- The turret of a level. Level 0, and any level the mod does not know,
-- is the launcher's own name.
function Launcher.name(level)
  if known(level) then
    return Names.LAUNCHER .. "-" .. level
  end
  return Names.LAUNCHER
end

Launcher.NAMES = { Names.LAUNCHER }
local LEVEL_OF = { [Names.LAUNCHER] = 0 }
for level = 1, MAX do
  Launcher.NAMES[#Launcher.NAMES + 1] = Launcher.name(level)
  LEVEL_OF[Launcher.name(level)] = level
end

-- The level of a turret name, or nil for any other entity.
function Launcher.level_of(name)
  return LEVEL_OF[name]
end

-- The automatic range of a level, in tiles.
function Launcher.range(level)
  local n = known(level) and level or 0
  return Balance.launcher.range + n * Balance.launcher.range_step
end

-- The hidden gun of a level.
function Launcher.gun(level)
  return Names.GUN .. (known(level) and level or 0)
end

return Launcher
```

```lua
-- A shallow copy of the named fields of t. A field that t lacks stays

function Common.pick(t, fields)
```

```lua
-- Decides whether the vanilla artillery flare can be limited to
-- artillery shells, so that the vanilla remote stops firing larva
-- launchers. Pure: it reads only its parameter.
local Names = require("core.names")

local Flare = {}

local VANILLA = "artillery-shell"

-- The ammo categories of one gun, as a list.
local function categories(gun)
  local a = gun.attack_parameters
  if not a then
    return {}
  end
  local out = {}
  if a.ammo_category then
    out[#out + 1] = a.ammo_category
  end
  for _, c in ipairs(a.ammo_categories or {}) do
    out[#out + 1] = c
  end
  return out
end

local function has(list, value)
  for _, v in ipairs(list) do
    if v == value then
      return true
    end
  end
  return false
end

-- guns: the gun prototypes of every artillery turret and wagon. Returns
-- "artillery-shell" when every gun except the larva launcher's own uses
-- only that category, and at least one does. Returns nil otherwise, so
-- the vanilla flare keeps drawing every category.
function Flare.vanilla_category(guns)
  local seen = false
  for _, gun in ipairs(guns) do
    local list = categories(gun)
    if not has(list, Names.AMMO) then
      for _, c in ipairs(list) do
        if c ~= VANILLA then
          return nil
        end
        seen = true
      end
    end
  end
  return seen and VANILLA or nil
end

return Flare
```

```lua
-- Whether the attacker is at war with a force. Without a launcher (it
-- was destroyed while the rocket flew), only the natives count.
local function at_war(attacker, force)
  if not attacker then
    return force.name == "enemy"
  end
  return force ~= attacker and not attacker.get_cease_fire(force) and not attacker.get_friend(force)
end

-- The landing blast. The launcher's force deals the damage, so kills
-- count for it.
local function blast(surface, position, launcher)
  local attacker = launcher and launcher.valid and launcher.force or nil
  local targets = surface.find_entities_filtered({
    position = position,
    radius = Balance.blast.radius,
  })
  for _, target in pairs(targets) do
    if
      target.valid
      and target.is_entity_with_health
      and Forces.blast_hits(target.force.name, at_war(attacker, target.force))
    then
      local cause = attacker and launcher or nil
      target.damage(Balance.blast.damage, attacker or "neutral", "explosion", nil, cause)
    end
  end
end

-- A larva rocket lands. The blast goes first, then the loaded monster
-- takes the nearest free spot, so the blast can't hurt it. With no free
-- spot, for example in water, the payload goes off where the rocket
-- landed. A projectile's source is the launcher, so the landing reads
-- the target position.
local function land(event, species, payload)
  local surface = game.get_surface(event.surface_index)
  local position = event.target_position
  if not surface or not position or surface.platform then
    return
  end
  blast(surface, position, event.source_entity)
  local monster = spawn(surface, position, species.units, Names.TAMED)
  if monster then
    load_monster(monster, payload)
    return
  end
  for _, effect in ipairs(Payloads.on_death({ payload.name }, position, entity_exists)) do
    effect.force = Names.TAMED
    surface.create_entity(effect)
  end
end
```

```lua
-- The highest range research a force finished, or 0. researched(name)
-- tells whether the force finished a technology. The editor or a
-- command can finish a higher level alone, so this takes the highest
-- finished level, not a count.
function Launcher.level(researched)
  for level = Balance.launcher.max_level, 1, -1 do
    if researched(Names.RANGE_TECH .. level) then
      return level
    end
  end
  return 0
end

-- The level of a launcher prototype name, or nil for any other name.
function Launcher.level_of(name)
  for level = 0, Balance.launcher.max_level do
    if Launcher.name(level) == name then
      return level
    end
  end
  return nil
end

function Launcher.is_range_tech(name)
  for level = 1, Balance.launcher.max_level do
    if name == Names.RANGE_TECH .. level then
      return true
    end
  end
  return false
end

-- The next step of a swap, after a step that worked (ok) or failed.
-- The shell runs the steps. This table makes sure that no failure loses
-- a launcher or its ammo.
local NEXT = {
  destroy = { [true] = "create", [false] = "give_back" },
  create = { [true] = "finish", [false] = "create_old" },
  create_old = { [true] = "finish", [false] = "spill" },
}

function Launcher.after(step, ok)
  local by_result = NEXT[step]
  return by_result and by_result[ok == true] or "stop"
end
```

```lua
-- The launcher level and the swap. This module is shell: it reads and
-- writes the game. control.lua calls it, and so do the in-game tests.
local Launcher = require("core.launcher")

local LauncherShell = {}

local AMMO = defines.inventory.artillery_turret_ammo

---@param force LuaForce
function LauncherShell.level(force)
  return Launcher.level(function(name)
    local tech = force.technologies[name]
    return tech ~= nil and tech.researched
  end)
end

-- Everything the new launcher must keep. A wire is kept as its connector
-- ID and the connector at the other end.
---@param old LuaEntity
local function read(old)
  local wires = {}
  for id, connector in pairs(old.get_wire_connectors(false)) do
    for _, connection in pairs(connector.connections) do
      wires[#wires + 1] = { id = id, target = connection.target }
    end
  end
  local behaviour
  local b = old.get_control_behavior()
  if b then
    ---@cast b LuaArtilleryTurretControlBehavior
    behaviour = {
      circuit_enable_disable = b.circuit_enable_disable,
      circuit_condition = b.circuit_condition,
      connect_to_logistic_network = b.connect_to_logistic_network,
      logistic_condition = b.logistic_condition,
      read_ammo = b.read_ammo,
    }
  end
  return {
    name = old.name,
    surface = old.surface,
    position = old.position,
    direction = old.direction,
    force = old.force,
    quality = old.quality,
    health = old.health,
    auto = old.artillery_auto_targeting,
    last_user = old.last_user,
    wires = wires,
    behaviour = behaviour,
  }
end

local function create(state, name)
  return state.surface.create_entity({
    name = name,
    position = state.position,
    direction = state.direction,
    force = state.force,
    quality = state.quality,
    raise_built = true,
  })
end

---@param new LuaEntity
local function restore(new, state, temp)
  new.health = state.health
  new.artillery_auto_targeting = state.auto
  if state.last_user then
    new.last_user = state.last_user
  end
  new.get_inventory(AMMO)[1].transfer_stack(temp[1])
  for _, wire in ipairs(state.wires) do
    if wire.target.valid then
      local connector = new.get_wire_connector(wire.id, true)
      if connector then
        connector.connect_to(wire.target, false)
      end
    end
  end
  if state.behaviour then
    local b = new.get_or_create_control_behavior()
    ---@cast b LuaArtilleryTurretControlBehavior
    for key, value in pairs(state.behaviour) do
      b[key] = value
    end
  end
end

-- Replaces a launcher with the prototype of another level. The ammo
-- waits in a script inventory, so its spoil timer keeps running. No
-- failure loses the launcher or its ammo (Launcher.after). Returns the
-- new launcher, or nil.
---@param old LuaEntity
---@param name string
function LauncherShell.swap(old, name)
  local state = read(old)
  local temp = game.create_inventory(1)
  local ammo = old.get_inventory(AMMO)
  temp[1].transfer_stack(ammo[1])
  local new
  local step = "destroy"
  local ok = old.destroy({ raise_destroy = true })
  while true do
    step = Launcher.after(step, ok)
    if step == "create" then
      new = create(state, name)
      ok = new ~= nil
    elseif step == "create_old" then
      new = create(state, state.name)
      ok = new ~= nil
    elseif step == "give_back" then
      ammo[1].transfer_stack(temp[1])
      break
    elseif step == "spill" then
      state.surface.spill_item_stack({
        position = state.position,
        stack = temp[1],
        force = state.force,
        allow_belts = false,
      })
      log("Abominable Ordnance: a larva launcher could not be rebuilt, its ammo lies on the ground")
      break
    else
      break
    end
  end
  if new then
    restore(new, state, temp)
  end
  temp.destroy()
  return new
end

-- Swaps every launcher of a force whose level differs from the force's
-- level. Runs once per research or force event, not every tick.
---@param force LuaForce
function LauncherShell.sync(force)
  local name = Launcher.name(LauncherShell.level(force))
  for _, surface in pairs(game.surfaces) do
    for _, entity in pairs(surface.find_entities_filtered({ name = Launcher.NAMES, force = force })) do
      if entity.valid and entity.name ~= name then
        LauncherShell.swap(entity, name)
      end
    end
  end
end

-- Swaps one newly built launcher to its force's level. A launcher that
-- already has the right level, such as the one a swap raises, stays.
---@param entity LuaEntity
function LauncherShell.on_built(entity)
  if not (entity and entity.valid and Launcher.level_of(entity.name)) then
    return
  end
  local name = Launcher.name(LauncherShell.level(entity.force))
  if entity.name ~= name then
    LauncherShell.swap(entity, name)
  end
end

return LauncherShell
```
