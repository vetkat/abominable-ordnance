# Slice 4 (feral behaviour) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use
> superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps
> use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Loaded monsters go feral when a player comes too close, when
they stay idle for 5 minutes, or by a small unstable chance. A feral
monster joins its own force, hunts the nearest enemy, and its payload
still goes off when it dies.

**Architecture:** A pure core module, `core/feral.lua`, holds every
decision: the size step, the feral radius, the too-close test, the idle
and unstable decision and the failed-hunt mark. `core/forces.lua` gets a
second rule for the feral force. A thin shell module, `shell/feral.lua`,
does the game work: going feral, the hunt, the too-close scan for one
player, the batch check for one entry and failed commands.
`control.lua` wires the events. The batch check reuses `core/trail.lua`
with its own cursor over `storage.loaded`.

**Tech Stack:** Factorio 2.1.24 Lua, busted for the core, factorio-test
for the in-game tests, `make check` for all gates.

**Spec:** `docs/superpowers/specs/2026-11-14-feral-design.md` (six EGM
rounds, round 6 clean. The maintainer accepted every default in "Calls
for the maintainer" on 2026-11-15).

In every step, `BUSTED` stands for
`lua5.2 /usr/lib/luarocks/rocks-5.2/busted/2.3.0-1/bin/busted --lua=lua5.2`.

## Global Constraints

- The target is Factorio 2.1, with and without Space Age.
- Every number lives in `core/balance.lua`, under `Balance.feral`.
- A core module never names `game`, `storage`, `script`, `defines`,
  `prototypes`, `rendering`, `helpers`, `remote`, `commands`, `rcon`,
  `settings`, `mods` or `data`. `spec/architecture_spec.lua` enforces
  this, also for table keys. The core gets plain values and booleans
  from the shell, never `defines` values.
- No file in `core/`, `shell/` or `control.lua` uses `math.random`. The
  shell passes the core a number from `random()` in `control.lua`.
- All state that changes during play lives in `storage`. A reader treats
  a missing field as its start value, so the slice needs no migration.
- A change to mod code gets a line under Unreleased in `CHANGELOG.md`.
- Commits: `make format`, `git add <files>` (never `-A`), `make stamp`,
  `git commit`, each as its own command. The PR body has the
  `## Review angles` section with all six angles, and the PR uses
  `gh pr merge --auto --squash`.
- Look up each Factorio API name in `.factorio-api/factorio/library/`.
- In-game tests destroy what they create before they assert, give every
  poll an upper bound, and use positions on the row `y = 3000`, from
  `x = 3000` on. No other test file uses that row.

  below (a wander, no mark) stays.

## Review Focus

- **A player in the map editor or without a character.** The scan must
  skip them, and no monster may go feral because of them. Task 4 pins
  it with an in-game test of a player force with no character near a
  monster.
- **Two players near the same monster in one scan.** The monster goes
  feral once, and the second player must not run `go_feral` on an entry
  that is already feral. Task 1 pins it with the busted case "a feral
  entry never goes feral again".
- **A feral monster that dies.** Its payload and acid trail belong to
  `ao-feral`, and its entry leaves `storage.loaded`. Task 4 pins the
  payload force in game.
- **An old save with loaded monsters.** Entries without `idle_since` or
  `checked_at` must not go feral at the first batch check. Task 5 pins
  it with the busted case "no `checked_at` means no unstable roll" and
  an idle case with `idle_since` nil.
- **A full force limit.** With 64 forces the mod must load, log one
  line, and keep every monster tamed. Task 3 pins the guard with an
  in-game test that calls the guard function with a limit that counts
  as full.

```lua
-- The rules for loaded monsters that go feral. Pure: it reads only its
-- parameters and other core modules. The shell passes plain values,
-- never game objects or defines.
local Balance = require("core.balance")
local Species = require("core.species")

local Feral = {}

-- A unit's position in its species list, from small (0) to behemoth.
local STEP = {}
local MAX_STEP = 0
for _, species in ipairs(Species.ALL) do
  for i, unit in ipairs(species.units) do
    STEP[unit[1]] = i - 1
    MAX_STEP = math.max(MAX_STEP, i - 1)
  end
end

-- The size step of a unit. A unit from another mod gets 0.
function Feral.size_step(name)
  return STEP[name] or 0
end

-- The feral radius of a monster with this many payloads.
function Feral.radius(name, payload_count)
  local f = Balance.feral
  local extra = math.max((payload_count or 1) - 1, 0)
  return f.radius + f.per_payload * extra + f.per_size * Feral.size_step(name)
end

-- The largest feral radius in the mod. The too-close scan searches this
-- far around each player.
function Feral.largest_radius()
  local f = Balance.feral
  return f.radius + f.per_payload * (f.max_payloads - 1) + f.per_size * MAX_STEP
end

function Feral.distance(a, b)
  local dx, dy = a.x - b.x, a.y - b.y
  return math.sqrt(dx * dx + dy * dy)
end

-- True if a player at this distance makes the monster go feral. A
-- feral monster never goes feral again.
function Feral.too_close(entry, distance, name)
  if entry.feral then
    return false
  end
  return distance <= Feral.radius(name, #entry.payloads)
end

-- True while the monster's last failed hunt is recent. A marked monster
-- wanders instead of hunting.
function Feral.marked(entry, tick)
  local f = Balance.feral
  return entry.failed_at ~= nil and tick - entry.failed_at < f.retry_wanders * f.rewander_ticks
end

-- True if a completed command marks the monster: a failed hunt that a
-- distraction did not cause.
function Feral.marks(failed, was_distracted, hunting)
  return failed and not was_distracted and hunting == true
end

return Feral
```

```lua
local Tamed = {}

-- The game allows 64 forces in all.
local FORCE_LIMIT = 64

-- True when one more force fits.
function Tamed.can_create(count)
  return count < FORCE_LIMIT
end

-- Sets one relation both ways, when the rule gives one.
local function set(a, b, rule)
  if a and rule ~= nil then
    a.set_cease_fire(b, rule)
    b.set_cease_fire(a, rule)
  end
end

-- Relates one force to the tamed and the feral force, by the rules in
-- core/forces.lua.
function Tamed.relate(force)
  set(game.forces[Names.TAMED], force, Forces.cease_fire(force.name))
  set(game.forces[Names.FERAL], force, Forces.feral_cease_fire(force.name))
end

-- Creates the tamed force and the feral force if they are missing, and
-- relates them to every force. A second call changes nothing. With a
-- full force limit the feral force is left out, and feral behaviour
-- stays off.
function Tamed.ensure()
  if not game.forces[Names.TAMED] then
    game.create_force(Names.TAMED)
  end
  if not game.forces[Names.FERAL] then
    if Tamed.can_create(#game.forces) then
      game.create_force(Names.FERAL)
    else
      log("Abominable Ordnance: the force limit is full, so loaded monsters never go feral")
    end
  end
  for _, force in pairs(game.forces) do
    Tamed.relate(force)
  end
end

return Tamed
```

-- Feral behaviour in the game. This module is shell: it reads and
-- writes the game. control.lua calls it, and so do the in-game tests.
-- The decisions live in core/feral.lua.
local Balance = require("core.balance")
local Feral = require("core.feral")
local Names = require("core.names")

local FeralShell = {}

-- Feral behaviour is off when the force limit kept the feral force out.
function FeralShell.available()
  return game.forces[Names.FERAL] ~= nil
end

-- The force of a loaded monster's payload and trail.
function FeralShell.force_of(entry)
  return entry.feral and Names.FERAL or Names.TAMED
end

-- A wander that ends after rewander_ticks, so the next batch check
-- searches again.
function FeralShell.wander(entry)
  local f = Balance.feral
  entry.hunting = false
  entry.unit.commandable.set_command({
    type = defines.command.wander,
    radius = f.search_radius,
    ticks_to_wait = f.rewander_ticks,
  })
end

-- A feral monster attacks the nearest enemy within seek_distance. A
-- marked monster wanders instead, and so does one with no target.
function FeralShell.hunt(entry, tick)
  local f = Balance.feral
  local unit = entry.unit
  if Feral.marked(entry, tick) then
    FeralShell.wander(entry)
    return
  end
  entry.failed_at = nil
  local target = unit.surface.find_nearest_enemy_entity_with_owner({
    position = unit.position,
    max_distance = f.seek_distance,
    force = unit.force,
  })
  if not target then
    FeralShell.wander(entry)
    return
  end
  entry.hunting = true
  unit.commandable.set_command({
    type = defines.command.attack_area,
    destination = target.position,
    radius = f.search_radius,
  })
end

-- Moves a loaded monster to the feral force, sends it hunting and shows
-- a warning above it.
function FeralShell.go_feral(entry, tick)
  local unit = entry.unit
  if not unit.valid or entry.feral or not FeralShell.available() then
    return
  end
  unit.force = Names.FERAL
  entry.feral = true
  FeralShell.hunt(entry, tick)
  rendering.draw_text({
    text = { "ao-feral.warning" },
    surface = unit.surface,
    target = { entity = unit, offset = { 0, -2 } },
    color = { r = 1, g = 0.2, b = 0.2 },
    scale = 1.5,
    alignment = "center",
    time_to_live = Balance.feral.warning_ticks,
  })
end

-- The too-close scan for one player. A player counts with a character,
-- on a force at peace with the tamed force, off a space platform. The
-- character's position is the vehicle's position when the player
-- drives.
function FeralShell.scan_player(player, tick)
  local character = player.character
  if not (character and character.valid) then
    return
  end
  local tamed = game.forces[Names.TAMED]
  if not tamed or not tamed.get_cease_fire(player.force) then
    return
  end
  local surface = character.surface
  if surface.platform then
    return
  end
  local position = character.position
  local units = surface.find_entities_filtered({
    position = position,
    radius = Feral.largest_radius(),
    force = Names.TAMED,
    type = "unit",
  })
  for _, unit in pairs(units) do
    local entry = storage.loaded[unit.unit_number]
    if entry and entry.unit == unit then
      local distance = Feral.distance(position, unit.position)
      if Feral.too_close(entry, distance, unit.name) then
        FeralShell.go_feral(entry, tick)
      end
    end
  end
end

return FeralShell

-- The chance that a monster goes feral by the unstable rule over
-- elapsed ticks. It grows with each payload.
function Feral.unstable_chance(payload_count, elapsed)
  if elapsed <= 0 or payload_count <= 0 then
    return 0
  end
  local p = Balance.feral.unstable_per_minute * payload_count
  return 1 - (1 - p) ^ (elapsed / 3600)
end

-- True if a tamed monster goes feral at this check: idle for idle_ticks
-- or more, or the unstable roll for the time since its last check. roll
-- is a random number in [0, 1) from the shell.
function Feral.decide(entry, tick, roll)
  if entry.feral then
    return false
  end
  if entry.idle_since ~= nil and tick - entry.idle_since >= Balance.feral.idle_ticks then
    return true
  end
  local elapsed = entry.checked_at and tick - entry.checked_at or 0
  return roll < Feral.unstable_chance(#entry.payloads, elapsed)
end
```

-- The batch check for one loaded monster. A feral monster without a
-- command hunts again. A tamed monster updates its idle clock and may
-- go feral. roll is a random number in [0, 1) from control.lua.
function FeralShell.check(id, tick, roll)
  local f = Balance.feral
  local entry = storage.loaded[id]
  if not entry or not entry.unit.valid then
    return
  end
  local unit = entry.unit
  if unit.surface.platform then
    return
  end
  if entry.feral then
    if not unit.commandable.has_command then
      FeralShell.hunt(entry, tick)
    end
    return
  end
  local natives = unit.surface.count_entities_filtered({
    position = unit.position,
    radius = f.search_radius,
    force = "enemy",
    limit = 1,
  })
  if natives > 0 then
    entry.idle_since = nil
    if not unit.commandable.has_command then
      unit.commandable.set_command({
        type = defines.command.attack_area,
        destination = unit.position,
        radius = f.search_radius,
      })
    end
  elseif entry.idle_since == nil then
    entry.idle_since = tick
  end
  local goes = Feral.decide(entry, tick, roll)
  entry.checked_at = tick
  if goes then
    FeralShell.go_feral(entry, tick)
  end
end

-- A feral monster's command ended. A failed hunt marks the monster
-- unless a distraction caused it, and every failure ends in a wander,
-- so an unreachable target can't start a loop of failed commands.
function FeralShell.completed(event)
  local entry = storage.loaded[event.unit_number]
  if not entry or not entry.feral or not entry.unit.valid then
    return
  end
  if entry.unit.unit_number ~= event.unit_number then
    return
  end
  if event.result ~= defines.behavior_result.fail then
    return
  end
  if Feral.marks(true, event.was_distracted, entry.hunting) then
    entry.failed_at = event.tick
  end
  FeralShell.wander(entry)
end
```
